# Air Cargo Analysis using SQL

## Project Overview
This project analyzes airline passenger data to identify regular customers,
busiest routes, and ticket sales performance using MySQL.

## Dataset
- Customer
- Passengers_on_flights
- Ticket_Details
- Routes

## SQL Concepts Used
- Joins
- Group By & Having
- Window Functions
- Stored Procedures
- Views
- Rollup
- Cursors
